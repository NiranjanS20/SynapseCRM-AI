# SynapseCRM AI Frontend

Next.js 15 App Router dashboard for the SynapseCRM AI platform.

## Run locally

1. Copy `.env.example` to `.env.local`.
2. Run `npm install`.
3. Run `npm run dev`.

## Highlights

- Authentication screens for Supabase-backed login and registration.
- Realtime workflow events through WebSockets.
- React Query for API-driven dashboards.
- Zustand for auth and live event state.
- Dark, atmospheric SaaS layout optimized for CRM analytics.
